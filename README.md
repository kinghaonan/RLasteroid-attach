# 小行星附着最优轨迹设计：基于强化学习的建模与分析

## 1. 引言

我本科期间主持了《小行星附着最优轨迹设计与仿真分析》大创项目，所以以此为题。

我在大创中使用了多面体模型获得高精度引力场数据，设计了神经网络，以航天器与小行星相对位置为输入，输出引力加速度矢量与引力梯度。其次，建立航天器动力学模型，以最小能量和燃料消耗为核心目标，通过切比雪夫伪谱法将连续最优控制问题转化为非线性规划（NLP）问题，采用序列二次规划（SQP）算法求解。最后，通过蒙特卡洛仿真验证鲁棒性。但是项目中使用了深度神经网络并没有利用强化学习进行最优轨迹的求解。

传统上，求解最优轨迹的过程被视为一个**确定性轨迹优化问题**，通过庞特里亚金极大值原理（PMP）求解。本文将小行星附着最优控制问题离散化表述为马尔可夫决策过程，使用打靶法对简化的小行星模型进行最优轨迹的求解得到**参考轨迹**，然后利用强化学习（RL）基于参考轨迹在**真实**的小行星引力场上进行求解。

**项目整体技术流程**：前期调研与基础模型复用 → 动力学建模 → 经典最优控制（打靶法求解参考轨迹）→ 强化学习MDP建模 → 仿真环境搭建 → PPO算法与网络架构搭建 → 模型热启动训练 → 仿真验证 → 总结与优化。

## 2. 问题抽象与动力学建模

### 2.1 非惯性系下的非线性动力学

小行星附着问题的核心难点在于其动力学环境。大部分小行星都有快速的自转且存在不规则引力场，而航天器的推力有限难以满足高精着陆要求。

在体坐标系下，探测器的运动方程不仅受到微弱且不规则引力的驱动，还受到旋转参考系引入的非惯性力耦合。探测器的运动方程可表示为：

```
dr/dt = v
dv/dt = -2ω×v - ω×(ω×r) + ∇U(r) + (T_max·u/m)·α
dm/dt = -T_max·u / (I_sp·g0)
```

从控制理论角度看，这是一个典型的**欠驱动、强耦合、非线性系统**。

- 前两项为非惯性系引入的虚拟力：`-2ω×v` 是科氏力；`-ω×(ω×r)` 是离心力
- 第三项 ∇U(r) 是引力加速度，是整个动力学模型中最具非线性特征的部分
- 第四项是推力加速度，体现了有限推力的幅值约束与方向自由度
- 质量变化方程是燃料最优控制的核心

#### 2.1.1 非惯性力的三维分量形式

将矢量叉乘展开为体固系下的分量形式：

```
科氏力分量:  [ 2ω·v_y,  -2ω·v_x,  0 ]
离心力分量:  [ ω²·x,    ω²·y,    0 ]
```

非惯性力在 x-y 平面产生耦合作用，z 轴方向不受自转非惯性力的直接影响。这一特性可用于简化强化学习的状态空间设计。

#### 2.1.2 高精度引力场建模：多面体模型+神经网络拟合

小行星引力场的不规则性是传统解析方法失效的根本原因。**多面体引力模型**通过将小行星表面离散为三角面片，可精确计算任意位置的引力势和引力加速度。

多面体模型虽然精度极高，但计算复杂度与三角面片数 N 成正比 O(N)，计算效率极低。我在大创中设计了一个引力场拟合神经网络：

- **输入**：探测器相对位置 r（3维）
- **输出**：引力加速度 ∇U(r)（3维）和引力梯度张量 ∇²U(r)（9维）
- **训练数据**：通过多面体模型预计算50万个采样点的引力数据

该神经网络实现了计算效率与精度的平衡，为后面强化学习进行了铺垫。

### 2.2 约束条件与多目标优化函数

#### 2.2.1 边界条件

- **初始边界条件**：r(t0)=r0,  v(t0)=v0,  m(t0)=m0
- **终端边界条件**：r(tf)=rf,  v(tf)=0,  m(tf)≥mp（软着陆核心要求）

#### 2.2.2 物理约束

- **推力幅值约束**：||T|| ≤ T_max
- **避障安全约束**：探测器距障碍物 ≥ d_safe
- **姿态约束**：姿态角不超过喷管摆动范围

#### 2.2.3 多目标优化函数

燃料最优性能指标（最小化推进剂消耗）：

```
J_fuel = (1/(I_sp·g0)) × ∫||T||dt
```

在强化学习框架中离散化为奖励函数的惩罚项：`R_cost = -λ × ∫||T||dt`

### 2.3 建模抽象

将最优控制问题离散化为马尔可夫决策过程。连续动力学抽象为：

```
dx/dt = f(x, u, t) + w(t)
```

其中 x = [r, v, m]^T 为扩展状态，u 为控制输入，w(t) 为噪声。

MDP四要素：

1. **状态抽象**：s = [r, v, m, T(r)]，T(r) 为局部地形特征
2. **动作抽象**：a = [u, αx, αy, αz]，u 为推力比，α 为方向
3. **转移概率**：s_{t+1} = RK4(s_t, a_t, Δt) + w_t
4. **奖励函数**：多目标优化函数离散化

## 3. 强化学习框架构建

### 3.1 状态空间

扩展为包含姿态的刚体模型：

```
s = [r_rel, v_rel, q, ω, m, T(r)]
```

### 3.2 奖励函数设计

**1. 势能塑形（Potential-based Reward Shaping）**：

```
R(s,a,s') = r_env + γ·Φ(s') - Φ(s)
Φ(s) = -k1·||r - r_target|| - k2·||v - v_target||
```

Telescoping Sum 性质：γ^{tf}·Φ(s_tf) - Φ(s_0)，势能函数**不改变最优解**，仅加速收敛。

**2. 燃料惩罚**：R_cost = -λ × ∫||T||dt

**3. 推力开关约束**：R_switch = -γ_switch × ΣΔN(t)

**4. 线性加权融合**：

```
R_total = λ1·R_prs + λ2·R_cost + λ3·R_switch
λ1=1.0,  λ2=0.12,  λ3=0.07
```

### 3.3 终端奖励

- 成功：R_success = +1000
- 失败：R_failure = -1000

### 3.4 环境建模

- **核心动力学**：有限推力全耦合方程 + RK4积分（Δt=1s）
- **不确定性**：引力场±5%、推力±3%、传感器噪声±10m/±0.1m/s
- **地形模型**：多面体地形模型，预计算坡度粗糙度

### 3.5 终止条件

- 成功：||r - r_target|| ≤ 5m 且 ||v|| ≤ 0.1m/s
- 撞击/逃逸/燃料耗尽/超时(t≥3600s)

## 4. 经典最优控制作为热启动

首先在简化物理模型（中心引力场）下，利用**打靶法（Shooting Method）**求解初始最优轨迹作为 RL 的"热启动"。利用标称轨迹 r_ref(t), v_ref(t) 构造势能型引导奖励。

### 4.1 庞特里亚金极大值原理 (PMP)

打靶法基于 PMP，将最优控制转化为两点边值问题（TPBVP）：

```
哈密顿量:  H = L(x,u) + λ^T·f(x,u)
最优控制:  u* = argmin H(x,u,λ)
状态方程:  dx/dt = ∂H/∂λ
协态方程:  dλ/dt = -∂H/∂x
```

推力方向与协态变量方向相反，幅值由切换函数决定（通常为 bang-bang 控制）。

### 4.2 打靶法求解流程

1. **定义目标函数**：输入初始协态变量 → 输出终端状态误差
2. **数值积分**：RK45 同时积分状态和协态方程
3. **迭代优化**：非线性求解器调整初始协态变量至收敛

在简化的中心引力场中更容易找到合适的初始猜测，高效获得物理上合理的轨迹。

## 5. PPO 算法实现

### 5.1 PPO 核心机理

选择**近端策略优化（PPO）**，通过限制策略更新幅度保证训练稳定性。

剪切目标函数：`J_CLIP = E[min(r_t·A_t,  clip(r_t, 1-ε, 1+ε)·A_t)]`

其中 r_t 为新旧策略概率比，A_t 为 GAE 优势估计，ε=0.2。

### 5.2 网络架构

- Actor：多层全连接，输出动作参数
- Critic：多层全连接，输出状态价值
- ReLU（隐藏层）+ Tanh（输出层）
- Adam 优化器，学习率 3×10^-4

### 5.3 项目实现

| 模块 | 技术 |
|------|------|
| 动力学 | 中心引力场 + RK4 积分 |
| 打靶法 | scipy L-BFGS-B 优化 |
| RL 环境 | Gymnasium |
| 算法 | stable-baselines3 PPO |
| 制导 | PD 矢量制导（径向+横向阻尼）|
